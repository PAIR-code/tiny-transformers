menu_book Symbol & Notation Glossary (H, W, PW, and Affinoid Logic)
x(d): Binary input bit (∈ {0, 1}) for dimension d=1..D.
X(d): 2-adic leaf disk embedding in B for binary input bit x(d).
PW(m, d): Learned Pool Weight parameter disk for Pool m, Dim d. Acts as a translation vector in Qp.
⊕ (Hsia Disk Addition): Non-Archimedean disk addition in Qp on the Berkovich line. For disks (c1, ρ1) and (c2, ρ2), their sum is (c1 + c2, max(ρ1, ρ2)).
H(m, d) = X(d) ⊕ PW(m, d): Hidden Pool Disk formed by Hsia disk addition (cH = cX + cPW, ρH = max(ρX, ρPW)).
W(k, m, d): Learned Target Constraint Disk in B for Class k, Pool m, Dim d. Each W(k, m, d) is a Berkovich disk (cW, ρW) defining the ideal affinoid target region in B that H(m, d) must fall inside to satisfy Class k's DNF clause. Click any W(k, m, d) badge on the edges or any Class node in the diagram to inspect its exact 2-adic disk values below!
AND (max Loss): Affinoid domain intersection across all D dimensions. Evaluates via supremum norm as the maximum distance/loss across dimensions.
OR (min Loss): Disjunctive Normal Form (DNF) union across all M pools. Evaluates as the minimum loss across pools.
Prob π(k): Affinoid softmax probability for Class k derived from logit scores Dk = -Lossk.
